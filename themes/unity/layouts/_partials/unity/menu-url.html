{{- /* Returns the address of one menu entry, so every menu the theme reads resolves its entries the same way. Context: the menu entry. A pageRef entry resolves to its page, which already carries the language prefix. Without a page, the entry falls back to its url. The theme reads the url as the site wrote it, because Hugo's .URL lowercases a root-relative url, strips characters such as ? from it, and prepends the baseURL's path even when the url already starts with it. A url with a scheme or host passes through, and any other resolves under baseURL like a Markdown link, with the language prefix. An entry whose pageRef names no page in the current language, and that sets no url, returns "", and every caller leaves it out. html/template keeps only the http, https, and mailto schemes in an href and replaces any other with #ZgotmplZ. The site's own config names the url, so a url with another scheme, such as tel: or sms:, comes back marked safe. A javascript:, vbscript:, or data: url stays a plain string, because each one runs or embeds content in the page, and html/template still replaces it. */ -}} {{- $u := "" -}} {{- with .Page -}} {{- $u = .RelPermalink -}} {{- else with .MenuConfig.URL -}} {{- $u = . -}} {{- $parsed := urls.Parse . -}} {{- if not (or $parsed.IsAbs $parsed.Host) -}} {{- $u = partial "unity/markup/site-url.html" (dict "path" . "lang" true) -}} {{- else if and $parsed.Scheme (not (in (slice "javascript" "vbscript" "data") $parsed.Scheme)) -}} {{- $u = safeURL . -}} {{- end -}} {{- end -}} {{- return $u -}}
