{{- /* Returns the address of one menu entry, so every menu the theme reads resolves its entries the same way. Context: the menu entry. A pageRef entry resolves to its page, which already carries the language prefix. Without a page, the entry falls back to its url. The theme reads the url as the site wrote it, because Hugo's .URL lowercases a root-relative url, strips characters such as ? from it, and prepends the baseURL's path even when the url already starts with it. A url with a scheme or host passes through, and any other resolves under baseURL like a Markdown link, with the language prefix. An entry whose pageRef names no page in the current language, and that sets no url, returns "", and every caller leaves it out. html/template keeps only the http, https, and mailto schemes in an href and replaces any other with #ZgotmplZ. The site's own config names the url, so a url with another scheme, such as tel: or sms:, comes back marked safe. A javascript:, vbscript:, or data: url returns "" with a warning instead, because the panel's script navigates to each url that unity/site-pages.html publishes, outside html/template's reach. Both callers render through partialCached, so the warning fires once per menu in each language. */ -}} {{- $u := "" -}} {{- $scheme := partial "unity/ui/script-scheme.html" (.MenuConfig.URL | default "") -}} {{- with .Page -}} {{- $u = .RelPermalink -}} {{- else with $scheme -}} {{- warnidf "unity-menu-scheme" "unity: the menu entry %q links a %s: url, which the theme leaves out." $.Name . -}} {{- else with .MenuConfig.URL -}} {{- $u = . -}} {{- $parsed := urls.Parse . -}} {{- if not (or $parsed.IsAbs $parsed.Host) -}} {{- $u = partial "unity/markup/site-url.html" (dict "path" . "lang" true) -}} {{- else if $parsed.Scheme -}} {{- $u = safeURL . -}} {{- end -}} {{- end -}} {{- return $u -}}
