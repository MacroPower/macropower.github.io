{{- /* The Unity HUD: tap Alt, type a menu command. The overlay depends on the page only through the focused app's icon, so this partial picks the icon and renders unity/hud/overlay.html once per language and icon through partialCached. Context: the page. The left tile shows the focused app's icon, like Unity. The page window is the only app, so the icon is the one of the unity/site-pages.html entry that the page is current for, or a browser window for a page that no entry claims. */ -}} {{- $reg := partialCached "unity/site-pages.html" . -}} {{- $icon := "launcher/browser-window" -}} {{- range $k, $p := $reg.pages -}} {{- if partial "unity/ui/is-current.html" (dict "page" $ "entry" $p) }}{{ $icon = $p.icon }}{{ end -}} {{- end -}} {{ partialCached "unity/hud/overlay.html" $icon $icon -}}
