{{- /* The two taxonomies the blog's lenses read, as a dict of plural taxonomy names. "category" feeds the sidebar's Places lenses, the chips on each post row and in the reader, the Dash's post keywords, and the home terminal's post cards. "series" feeds the sidebar's Series lenses. A site names either one through params.blog.taxonomies. Without a category there, the blog reads "categories", or "tags" when the language's pages have tags and no categories, so a site that tags its posts shows its tags without config. Call it through partialCached, which keeps one cache per language. */ -}} {{- $category := site.Params.blog.taxonomies.category -}} {{- if not $category -}} {{- $category = "categories" -}} {{- if and (not (index site.Taxonomies "categories")) (index site.Taxonomies "tags") -}} {{- $category = "tags" -}} {{- end -}} {{- end -}} {{- return dict "category" $category "series" (site.Params.blog.taxonomies.series | default "series") -}}
