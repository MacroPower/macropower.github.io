{{- /* Inlines assets/unity/icons/.svg by body. Icons that paint with their own defs (gradients/filters referenced as url(#id), or in-file href="#id" uses) get those ids suffixed with a per-call counter: the same icon is inlined several times per page (launcher tile, dash tile, icon vault), id lookups resolve to the first match in the whole document, and when that first copy sits in a hidden subtree (e.g. the SSR-hidden Studio launcher tile) browsers drop the paint and every later copy renders with transparent fills. Only ids the file both defines and references are rewritten, so cross-file defs (lang-symbols' #lang-* / #pf-folder-*, consumed by other partials via ) keep their stable names. unity/ui/icon-source.html reads each file once per build. This partial must stay uncached, because caching it would collapse the per-call suffixes back into duplicates. A cached partial that calls it is safe, because the counter never repeats a value. */ -}} {{- $src := partialCached "unity/ui/icon-source.html" . . -}} {{- $c := $src.svg -}} {{- with $src.ids -}} {{- $n := math.Counter -}} {{- range . -}} {{- $c = replace $c (printf `id="%s"` .) (printf `id="%s-%d"` . $n) -}} {{- $c = replace $c (printf `url(#%s)` .) (printf `url(#%s-%d)` . $n) -}} {{- $c = replace $c (printf `href="#%s"` .) (printf `href="#%s-%d"` . $n) -}} {{- end -}} {{- end -}} {{- $c | safeHTML -}}
