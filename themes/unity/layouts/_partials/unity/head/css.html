{{- /* Builds the site's one stylesheet with css.Build and emits its link plus font preloads. css.Build lowers the native nesting for the target browsers and publishes the fonts main.css references with hashed names, so the preloads read their URLs from the build's artifacts. The entry puts assets/unity/css/main.css in the unity.theme cascade layer, and the syntax highlighter's classes for the site's markup.highlight.style in the later unity.chroma layer. A site that sets markup.highlight.noClasses to false therefore gets colored code without inline styles, and the highlight style's colors win over the theme's. A site's assets/css/custom.css comes last with no layer, so its rules beat every theme rule whatever their specificity, except the theme's !important declarations. css.Build moves an external @import in it to the top of the output, where browsers honor it. Each accent preset from unity/accents.html gets a rule in the unity.theme layer that sets the four --up-accent tokens on when its data-up-accent names the preset, and on the preset's swatch in the Preferences dialog. A site's custom.css sits outside the layers, so an accent token it sets beats every preset. params.desktop.wallpaper sets --up-wallpaper to an image in a rule that follows main.css in the unity.theme layer, so the rule beats main.css's default and custom.css beats the rule. css.Build publishes an image under assets/ with a hashed name and leaves a URL as written. A path under static/ resolves against the site's baseURL and goes in externals, so css.Build leaves it as written too. The partial never searches the page's bundle, because partialCached shares one result across pages. Context: the page. Call it through partialCached keyed on whether the page is the home terminal (unity/is-terminal.html), the only input that changes the output. */ -}} {{- $entry := `@layer unity.theme, unity.chroma; @import "/unity/css/main.css" layer(unity.theme); Ubuntu Mono 400 paints the home terminal. */ -}} {{- $preload := slice "ubuntu-400-latin" -}} {{- if partial "unity/is-terminal.html" . }}{{ $preload = $preload | append "ubuntu-mono-400-latin" }}{{ end -}} {{- range $main.Data.Artifacts -}} {{- if eq .MediaType.MainType "font" -}} {{- $face := replaceRE `-[A-Z0-9]+\.woff2$` "" (path.Base .RelPermalink) -}} {{- if in $preload $face }} {{- end -}} {{- end -}} {{- end -}} {{- $css := $main | resources.Fingerprint }}
