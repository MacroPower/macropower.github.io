{{- /* Builds the site's one stylesheet with css.Build and emits its link plus font preloads. css.Build lowers the native nesting for the target browsers and publishes the fonts main.css references with hashed names, so the preloads read their URLs from the build's artifacts. The target list names the oldest version of each browser that the theme supports, and the Requirements in README.md repeat it. css.Build lowers the nesting for those versions but leaves features such as :has() and color-mix() as written, so every target must support them. Firefox 121 is the first Firefox with :has(). The @media (scripting: none) blocks need Chrome 120 and Safari 17. Older versions skip those blocks, so only a visitor with JavaScript turned off loses the fallback styles there. browser-targets.test.ts under assets/unity/js checks the list against the features the stylesheet uses. The entry puts assets/unity/css/main.css in the unity.theme cascade layer, and the syntax highlighter's classes for the site's markup.highlight.style in the later unity.chroma layer. A site that sets markup.highlight.noClasses to false therefore gets colored code without inline styles, and the highlight style's colors win over the theme's. A site's assets/css/custom.css comes last with no layer, so its rules beat every theme rule whatever their specificity, except the theme's !important declarations. css.Build moves an external @import in it to the top of the output, where browsers honor it. Each accent preset from unity/accents.html gets a rule in the unity.theme layer that sets the --up-accent tokens on when its data-up-accent names the preset, and on the preset's swatch in the Preferences dialog. A site's custom.css sits outside the layers, so an accent token it sets beats every preset. params.desktop.wallpaper sets --up-wallpaper to an image in a rule that follows main.css in the unity.theme layer, so the rule beats main.css's default and custom.css beats the rule. css.Build publishes an image under assets/ with a hashed name and leaves a URL as written. A path under static/ resolves against the site's baseURL and goes in externals, so css.Build leaves it as written too. The partial never searches the page's bundle, because partialCached shares one result across pages. Context: the page. Call it through partialCached keyed on whether the page is the home terminal (unity/is-terminal.html), the only input that changes the output. */ -}} {{- $entry := `@layer unity.theme, unity.chroma; @import "/unity/css/main.css" layer(unity.theme); @import "/unity/css/chroma.css" layer(unity.chroma); ` -}} {{- if resources.Get "css/custom.css" }}{{ $entry = print $entry `@import "/css/custom.css";` }}{{ end -}} {{- with (partialCached "unity/accents.html" . site.Language.Name).presets -}} {{- $rules := slice -}} {{- range . -}} {{- $rules = $rules | append (printf `:root[data-up-accent=%q],.up-accent-swatch[data-up-accent=%q]{--up-accent:%s;--up-accent-light:%s;--up-accent-dark:%s;--up-accent-darker:%s;--up-accent-lighter:%s}` .name .name .color .light .dark .darker .lighter) -}} {{- end -}} {{- $entry = printf "%s\n@layer unity.theme{%s}" $entry (delimit $rules "\n") -}} {{- end -}} {{- $externals := slice -}} {{- with site.Params.desktop.wallpaper -}} {{- $u := urls.Parse . -}} {{- $url := . -}} {{- if not (or $u.IsAbs $u.Host) -}} {{- $path := strings.TrimPrefix "/" (strings.TrimPrefix "./" $u.Path) -}} {{- if resources.Get $path -}} {{- $url = printf "/%s" $path -}} {{- else -}} {{- $url = partial "unity/markup/site-url.html" (dict "path" (printf "/%s" (strings.TrimPrefix "/" (strings.TrimPrefix "./" $u.EscapedPath)))) -}} {{- $externals = $externals | append $url -}} {{- end -}} {{- end -}} {{- $entry = printf "%s\n@layer unity.theme{:root{--up-wallpaper:url(%q) center/cover no-repeat}}" $entry $url -}} {{- end -}} {{- /* importContext takes a copy of the highlighter's classes.
