Firefox 121 is the first Firefox with :has(). The @media (scripting: none) blocks need Chrome 120 and Safari 17. Older versions skip those blocks, so only a visitor with JavaScript turned off loses the fallback styles there. browser-targets.test.ts under assets/unity/js checks the list against the features the stylesheet uses. css.Build reads only the files that every language shares, so it runs once per site and publishes each font once. Its entry puts assets/unity/css/main.css in the unity.theme cascade layer. A site's assets/css/custom.css follows with no layer, so its rules beat every theme rule whatever their specificity, except the theme's !important declarations. css.Build moves an external @import in it to the top of the output, where browsers honor it. A language can set its own highlight style, accent presets, and wallpaper, so the partial appends their rules to the build's output as plain CSS. Each language whose rules differ links a stylesheet of its own. Never add those rules to the css.Build entry, because a second build for a language publishes each font again and Hugo warns of duplicate target paths. The syntax highlighter's classes for the language's markup.highlight.style go in the later unity.chroma layer. A site that sets markup.highlight.noClasses to false therefore gets colored code without inline styles, and the highlight style's colors win over the theme's. Each accent preset from unity/accents.html gets a rule in the unity.theme layer that sets the --up-accent tokens on when its data-up-accent names the preset, and on the preset's swatch in the Preferences dialog. The partial never searches the page's bundle, because partialCached shares one result across pages. Context: the page.
