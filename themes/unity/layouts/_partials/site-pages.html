{{- /* The canonical registry of the desktop's site pages — the single source of truth for every chrome surface that presents them: launcher.html — the dock tiles (launcherOrder) hud.html — the focused-app icon (launcherOrder, with a fallback) dash.html — the Applications category (dashOrder, kw haystacks) top-panel.html — the File menu's "Open " rows (launcherOrder) ui/runtime.html — UP_SITE.nav, the URL map behind top-panel.ts nav: The registry is driven by the site's [menu.main] configuration: one entry per page, ordered by weight, keyed by identifier (falling back to the anchorized name). Home is implicit and always first. Per-entry [menu.main.params] tune the desktop presentation: icon — launcher artwork under assets/unity/icons/ (e.g. "launcher/cv"); defaults by identifier below, generic browser window otherwise match — "exact" or "prefix": how the page claims the current URL for launcher active state (default "prefix") kw — the Dash's search haystack (defaults by identifier, else the lowercased name) dashLabel — Dash tile label override (the home page shows as "Terminal") dashIcon — Dash tile icon override launcher — set false to keep the page off the dock (still in the Dash); set "running" to dock it only while it is the current page, like the Studio's running-app tile (also off the File menu) dash — set false to keep the page out of the Dash Returns (dict "pages" dict> "launcherOrder" ... "runningOrder" ... "dashOrder" ...): launcherOrder is the dock and File menu, runningOrder the pages docked only while current, dashOrder the Dash's Applications.
